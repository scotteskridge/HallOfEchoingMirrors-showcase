# Summary page — notes

Starting point: `DesignNotes/mockups/Increlution summary screen Screenshot.png` (the user, 2026-09-29), described as "adequate, but massively reworked to fit this game's art style and goals".

`2026-09-29-summary-proposal.html` is Claude's proposal (a proposal, not a decision). The buttons at the top switch between the three run endings.

What it takes from Increlution:
- a one-sentence headline with the run time
- skills shown as ×before › ×after
- a strip showing where the run's time went

What it adds, from GDD §13a *Legibility* and *Benchmarks*:
- this run, last run and best in the headline, including when the result is worse
- the time split: travel, workings, searching, stalled, and nothing queued
- findings for where the queue stalled or ran out
- a count of the actions that were added automatically
- a milestones table with this run, last and best

All the wording and numbers in it are placeholders.

**The user's feedback (2026-09-29), already applied to the mock-up:**
- The run clock only runs while Clara is doing an action, so there is no idle or stalled time.
- The time strip has one slice per skill she spent time on, each with the skill's icon.
- *What she learned* sits directly under the strip and uses the skill icons.
- Milestones table columns: improvement ± · this run · last run · previous run.
- "Best" means the fastest time to reach a milestone. Ending a run early only means fewer milestones were reached.
- A wall is a challenge that needs a stat or pool to be high enough. None is built yet; the lab could hold the first one.
