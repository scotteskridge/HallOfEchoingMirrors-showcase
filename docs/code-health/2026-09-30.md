## Good patterns to keep

- **Tick-for-tick save test plus set-up asserts** (`RunSaveTests.cs:76-110`, `DrainTests.cs:36`): run the original and the reloaded game side by side, compare about 15 fields, and assert the set-up so a test can't pass vacuously. `AVersion20Save_PastTheReopeningSwitch_…` in `ExploringTests` is the model for every future save-version bump.
- **Cache the delegate, not the lambda** (`Simulation.Tasks.cs:407-412`): `_fitsCarried` and `_fitsHere` are built once, with a comment saying why a per-call lambda would allocate every tick. Copy this wherever a hot path needs a predicate.
