# GAME TEXT - English
# Hall of Echoing Mirrors
#
# Every line of on-screen text the game writes, in one place. (Names of rooms, tasks, items and
# switches are on their own assets; story passages and blurbs have their own files.)
#
# HOW TO EDIT
#   Each line is   key: text
#   Change the text freely. Never change the key: it's how the game finds the line.
#   {words in braces} are filled in by the game (a number, a name). Move them, keep the braces.
#   Any number can be written as 1st, 2nd, 3rd...: put :ordinal inside the braces, e.g. {loop:ordinal}.
#   \n starts a new line. <b>bold</b> and <i>italics</i> work.
#   ## starts a section (the section name goes in front of each key: "results.time").
#   Lines starting with # are notes, ignored by the game.
#   Save the file and the game updates, even while playing.
#   A missing key shows on screen as [section.key?], with a warning in the Console.
